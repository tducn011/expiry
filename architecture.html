🔌 3. Chi tiết cách các thành phần nối với nhau
A

Môi trường Local Dev (Vite Dev Server)

Frontend chạy React 19 tại cổng 8443. Trong file vite.config.ts có cấu hình proxy: proxy: { "/api": { target: "http://127.0.0.1:3001", changeOrigin: true } }. Trình duyệt gửi request tới /api/v1/..., Vite tự động chuyển tiếp tới cổng 3001 của container expiry-api.

B

Môi trường Production (Vercel + Cloudflare Tunnel)

Frontend triển khai trên Vercel. Trên homeserver có dịch vụ tailscale-funnel tạo đường hầm bảo mật HTTPS cố định https://homeserver.tailc535bb.ts.net chuyển tiếp vào backend API (cổng 3001) và Python OCR service. File vercel.json dùng luật rewrite chuyển toàn bộ /health, /api/*, /scan* sang URL đường hầm cố định này.

C

Xác thực & Bảo mật (Cookie + CSRF + Idempotency)

Phiên đăng nhập được quản lý bằng cookie HttpOnly, SameSite=Lax (__Host-expiry_session trên production). Các thao tác thay đổi dữ liệu (POST/PUT/DELETE) bắt buộc có header X-CSRF-Token và header Idempotency-Key (UUID ngẫu nhiên) để chống ghi đúp dữ liệu khi mạng chập chờn.

1

Gửi ảnh từ Node API sang Python Container

Khi người dùng bấm "Quét nhãn", FE gửi ảnh dạng multipart hoặc base64 đến POST /api/v1/scans. Node API gọi sang container Python qua mạng nội bộ Docker: http://python-scan:8000/scan với timeout 10 giây.

2

Tầng Fast Path: Tesseract OCR cục bộ

Python tiền xử lý ảnh bằng thư viện Pillow (giới hạn dung lượng 5MB). Sau đó chạy Tesseract OCR với tập ngôn ngữ eng+vie trong thời hạn 2.5 giây. Module date_parser.py phân tích cấu trúc ngày (HSD, NSX, Best Before, Use By).

3

Tầng Fallback: Vision LLM (Gemini / Ollama)

Nếu ảnh mờ, chữ in kim đứt khúc hoặc nhãn có nhiều ngày gây nhập nhằng (ambiguous), hệ thống tự kích hoạt vision_llm_adapter.py gọi Gemini API (hoặc Ollama trên host qua host.docker.internal:11434) để đọc đúng nhãn bao bì và tên món ăn.

1

Kết nối Connection Pool qua mysql2

Node API khởi tạo pool tối đa 10 kết nối tới mysql:3306 (user expiry_app, db expiry_dev). Mỗi kết nối được gán múi giờ chuẩn UTC: SET SESSION time_zone='+00:00'.
